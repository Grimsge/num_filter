# Фильтр чисел

Практическая работа №2: модульное и мутационное тестирование.

## Описание

Модуль `num_filter.py` — фильтрация коллекции чисел по признаку:

- простые числа;
- чётные / нечётные;
- числа Фибоначчи.

Дополнительно: чтение чисел из CSV и вывод результатов в терминал.

## Структура

- num_filter.py — модуль
- numbers.csv — входные данные
- README.md — этот файл

## Запуск

python num_filter.py

Файл numbers.csv должен лежать рядом. Формат — колонка value:

```
value
1
2
3
```

## Функции

| Функция | Назначение |
|---------|-----------|
| `is_prime(n)` | простое ли число |
| `is_even(n)` | чётное ли число |
| `is_odd(n)` | нечётное ли число |
| `is_fibonacci(n)` | число Фибоначчи ли |
| `filter_primes(numbers)` | оставить простые |
| `filter_even(numbers)` | оставить чётные |
| `filter_odd(numbers)` | оставить нечётные |
| `filter_fibonacci(numbers)` | оставить числа Фибоначчи |
| `read_numbers_from_csv(path)` | чтение из CSV |
| `print_results(numbers)` | вывод в терминал |
